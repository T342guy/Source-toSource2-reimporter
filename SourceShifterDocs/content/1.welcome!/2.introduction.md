SourceShifter is a work-in-progress migration tool that aims to help the community in terms of model support between the 2 generations of source engines, mainly aimed at the SFM and S2FM communities.

SourceShifter's goal is to make an easy-to-use, minimalist, and user-friendly migration tool for those in the SourceFilmmaker communities. SourceShifter Will hopefully open up more ease in porting models from Source1 to Source2, hoping to bridge the gap in model support between the 2 engine generations.

::accordion

  :::accordion-item{label="For the unfamiliar; A quick Source history recap." icon="i-lucide-circle-help"}
  The Source engine created by VALVe has 2 generations. Source, used to create games like CS:GO and DOTA, then the next generation being Source 2. Source 2 has been used to create newer games like CS2 and Half-Life:alyx.\
since GDC 2015, the year and event that VALVe announced the Source 2 engine technology, they have since stopped using the Source 1 engine.
So due to the huge leap in changes between the 2 generations in engine tech, Source 1 formats have become completely incompatable with the Source 2 engine.
  :::
